# Digital_analytics_insights
Digital programme monitoring and insights using Python, PostgreSQL, SQL and Power BI.
## Project Overview
This project simulates a digital development programme monitoring workflow. It explores how data cleaning, SQL analysis, and data visualization can support programme oversight, implementation tracking, financial monitoring, and evidence-based decision-making.

## Objectives
•	Assess the overall digital project portfolio.
•	Monitor project implementation against planned progress.
•	Identify budget utilization issues and potential overspending.
•	Compare project performance across countries and digital pillars.
•	Examine female beneficiary representation.
•	Identify data-quality exceptions before reporting findings.
•	Translate analytical results into actionable management insights.
## Tools & Technologies
•	Python: Data cleaning and preparation.
•	PostgreSQL: Data storage and querying.
•	SQL: Portfolio analysis, financial monitoring, progress tracking, and data-quality checks.
•	Power BI: Dashboard development and visualization.
